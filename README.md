# It's about `Time`

A two-hour, hands-on Ruby workshop for EuRuKo 2026.

This repository contains exercises we will work on together. It is based on a fictional `Meridian` software, a stargazing session planner.

## Install

```sh
git clone https://github.com/thoughtbot/its-about-time-workshop.git
cd its-about-time-workshop
bundle install
bin/doctor
```

`bin/doctor` checks that your Ruby, your gems and your time zone database match
everyone else's. Green tick means you're done and can close your laptop until
the day.

During the workshop:

```sh
rake e1         # run one exercise
rake doctor     # re-check your setup
```

Each block has a `README.md` with the task and some progressive hints.

The exercises are independent, so nothing depends on another's solution.
